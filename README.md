# Exercícios Básicos de PHP 🐘

Repositório dedicado ao estudo e prática dos fundamentos da linguagem PHP, focado em construir uma base sólida para o desenvolvimento de aplicações modernas.

## 🛠️ Tecnologias e Ambiente
*   **Linguagem:** PHP 8.3.
*   **Infraestrutura:** Docker e Docker Compose para garantir paridade entre os ambientes.
*   **Sistema Operacional:** Desenvolvido em ambiente Ubuntu Standard (GNOME).
*   **Padrão de Código:** Aplicação de Clean Code em todos os scripts.

## 📂 Organização do Projeto
As pastas deste repositório foram organizadas com prefixos numéricos (ex: `01-`, `02-`). Esta escolha foi feita propositalmente por dois motivos:

1.  **Ordenação Lógica:** Os sistemas de arquivos e o GitHub organizam pastas por ordem alfabética. A numeração garante que os tópicos apareçam na ordem cronológica de aprendizado (ex: Variáveis antes de Banco de Dados).
2.  **Roteiro de Estudo (Roadmap):** Funciona como um guia visual para recrutadores e outros desenvolvedores acompanharem a evolução técnica e a curva de aprendizado dos conceitos abordados.

## 📖 Conteúdo do Repositório
Baseado no cronograma de estudos, o projeto abrange:

*   **01-Fundamentos:** Variáveis, Constantes e Tipos de Dados.
*   **02-Operadores:** Aritméticos, Lógicos, Comparação e Ternários.
*   **03-Vetores e Matrizes:** Manipulação de arrays e coleções de dados.
*   **04-Funções Internas:** Manipulação de strings, datas e formatação de caracteres.
*   **05-Condicionais:** Estruturas `if`, `else`, `elseif` e `switch case`.
*   **06-Estruturas de Repetição:** Loops `for`, `while`, `do while` e `foreach`.
*   **07-Interatividade:** Manipulação de formulários (GET/POST), Cookies e Sessões.
*   **08-Banco de Dados:** Integração completa com MySQL (Conexão, CRUD e organização de arquivos).

## 🚀 Como Executar
1.  Certifique-se de ter o Docker instalado.
2.  Clone o repositório:
    ```bash
    git clone [https://github.com/RochaTechAI/exercicios-php-basico.git](https://github.com/RochaTechAI/exercicios-php-basico.git)
    ```
3.  Suba o container:
    ```bash
    docker compose up -d
    ```
4.  Acesse `localhost:8080` no navegador para interagir com os exercícios através do menu dinâmico.
